# FoxlyTV downloads

[Download FoxlyTV](https://tm1331mt.github.io/FoxlyTV-downloads/) voor Windows of een Mac met Apple Silicon.

Bekijk [alle versies en controlesommen](https://github.com/TM1331MT/FoxlyTV-downloads/releases).

Pak de ZIP volledig uit en open FoxlyTV starten.cmd (Windows) of FoxlyTV starten.command (Mac). Node.js is inbegrepen. Gebruik de inloggegevens van je eigen IPTV-aanbieder. FoxlyTV levert zelf geen abonnement of content.

Bijwerken: stop de oude versie en pak de nieuwe ZIP uit in een nieuwe map. Je instellingen en bibliotheek blijven op dezelfde computer bewaard.
